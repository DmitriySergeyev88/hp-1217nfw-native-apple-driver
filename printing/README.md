# HP M1217 Native Print 0.1.0 — офлайн-сборка

Отдельный нативный arm64-фильтр CUPS для HP M1217nfw. Вход и выход — URF, 600×600 dpi, 8-битный sGray. Растеризация PDF остаётся штатной macOS; новый фильтр заменяет упаковку пикселей, не их значения. Размеры, ориентация и все байты заголовков страниц сохраняются. Изображения не уменьшаются, оттенки не квантуются, резкость/контраст/полутона не меняются.

Кодировщик динамическим программированием подбирает минимальную длину последовательности стандартных repeat/literal-команд каждой строки; одинаковые строки объединяются по 256. Время кодирования линейно по числу пикселей; память фильтра ограничена несколькими строками и таблицами до 12000 пикселей, без полного изображения в памяти. Выход передаётся потоково. Проверка входа отвергает другой dpi/цвет, обрезанные данные, неверные длины, чрезмерные размеры и несовпадение числа страниц; ошибка сообщает CUPS о неуспехе. На повреждённом входе часть потока уже может быть выдана до обнаружения ошибки.

Исходные правила URF сверены с [OpenPrinting CUPS raster-stream.c](https://github.com/OpenPrinting/cups/blob/master/cups/raster-stream.c); реализация собственная. Используются стандартные команды, без PCLm, транспортного gzip и изменения прошивки. Команда заполнения белым остатка строки принимается, но не генерируется: для такого входа результат может быть больше. Оптимальность касается repeat/literal-пакетов, не произвольного сжатия изображения.

**Это готовая экспериментальная сборка, не подтверждённое ускорение принтера.** Для сложной фотографии сжатие без потерь может почти не сократить данные. Ранее наблюдалась медленная обработка принтером; новый код не устраняет доказанно ограничение его памяти/прошивки. Побайтовое равенство растра не заменяет аппаратную проверку качества и совместимости.

## Сборка и проверки без принтера

Требуются Apple Silicon, macOS 27.2, Command Line Tools и Python 3; сторонних библиотек нет.

```sh
python3 printing/build.py
python3 printing/test_printing.py
python3 printing/prepare.py input.pdf output.urf --media A4
```

`prepare.py` лишь создаёт локальный файл: не использует lp/lpr/IPP и не отправляет задания. Отказывается перезаписывать результат, включая символьные ссылки. Сохраняйте параметры исходного PDF: утилита предназначена для PDF уже с нужной раскладкой страницы. Cmd+P масштаб и раскладку задаёт приложение.

Сборка: `printing/build/HP-M1217-Native-Print-0.1.0-arm64.pkg`, отдельный исполняемый фильтр и SHA256SUMS. Пакет не подписан Developer ID и не нотариализован; фильтр имеет ad-hoc подпись. Поддержка macOS 28 не проверена.

## Будущая установка — в текущей задаче НЕ выполняется

Пакет содержит только `/Library/Printers/HPNative1217`: фильтр, PPD, лицензию и этот документ. Отказывается заменять существующий каталог или ссылку. Не создаёт и не меняет очереди, не затрагивает сканер. Для Cmd+P впоследствии нужна отдельная очередь с этим PPD и существующим IPP URI устройства. Существующую HP_M1217_Modern заменять нельзя. Регистрация новой очереди, разрешения CUPS и физическая печать требуют отдельного этапа проверки.

Откат будущей установки: удалить только созданную новую очередь (после проверки отсутствия заданий), затем сохранить или убрать `/Library/Printers/HPNative1217`. Старые очереди и их PPD не менять. Сейчас откат не требуется: система не изменяется.
