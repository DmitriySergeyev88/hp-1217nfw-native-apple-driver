# HP M1217 PCLm 600 — отдельная очередь macOS

Нативный arm64-фильтр для Cmd+P. macOS подготавливает серый растр A4 при 600 dpi; фильтр кодирует его полосами JPEG Q90 в PCLm. Исправлены разделители числовых полей и порядок запуска полос для прошивки 20200618. JPEG — сжатие с потерями; исходное разрешение страницы 600 dpi сохраняется, но побайтовая идентичность растра не заявляется.

Очередь: `HP_M1217_PCLm_600`, отображаемое имя `HP M1217 PCLm 600`, адрес `ipp://<IPv4 МФУ>:631/ipp/print`. В Cmd+P выберите эту очередь и A4; масштаб задавайте в приложении. Поддерживается один режим: A4, серый, 600 dpi, односторонняя печать. Другие форматы и прежний способ печати остаются в исходной AirPrint.

Фильтр установлен отдельно в `/Library/Printers/HPNative1217PCLm/Filters/hp-m1217-pclm`, без Python, Rosetta и сторонних библиотек. Apple ImageIO создаёт JPEG; это другой кодировщик, чем Pillow в ручной пробе. Физически проверен один файл Python-прототипа в 600 dpi; нативный фильтр и путь Cmd+P проверены только офлайн до новой разрешённой печати. Скорость/качество всей очереди пока не подтверждены аппаратно.

Сборка: `python3 build.py`. Офлайн-тесты: `python3 test_filter.py` (для тестов нужны Pillow и pypdf). Подпись ad-hoc, без Developer ID/нотаризации; macOS 28 не проверялась.

PPD использует [cupsFilter2](https://www.cups.org/doc/spec-ppd.html) с выходным MIME application/PCLm. Для офлайн-конвертации cupsfilter используйте `-m printer/HP_M1217_PCLm_600 -e`, а не прямой MIME application/PCLm. cupsfilter запускается в пользовательской сессии, поэтому такая проверка не заменяет аппаратную печать из CUPS.

Установка выполняется install.sh от администратора, без отправки задания. Существующий каталог/очередь не заменяются. rollback.sh удаляет только новую пустую очередь и переносит её каталог в резервную папку с отметкой времени. AirPrint, очередь Native Test, настройки принтера по умолчанию и сканеры не изменяются.

## Исправление входа Cmd+P

PPD принимает application/pdf. Нативный фильтр запускает только системный cgpdftoraster, задавая FINAL_CONTENT_TYPE=image/urf исключительно этому дочернему процессу; конечный MIME для backend остаётся application/PCLm. Это устраняет ошибку expected URF raster при общем окружении CUPS. Офлайн-тест воспроизводит FINAL_CONTENT_TYPE=application/PCLm и проверяет вход PDF через stdin и filename, а также отказ дочернего процесса.

Для единого выпуска используйте HP M1217 Setup и uninstall.sh из основного README. install.sh/rollback.sh здесь относятся только к отдельной установке фильтра; install.sh требует IPv4 аргументом. Цель сборки — macOS 11.0, фактически проверена macOS 27.2.
