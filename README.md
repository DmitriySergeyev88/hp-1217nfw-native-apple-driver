# HP M1130 / M1210 / M1217 — Native Print & Scan для Apple Silicon

[English](README.en.md) · [Скачать единый установщик](dist/HP-M1217-Native-Print-Scan-0.3.0-arm64.pkg) · [SHA256](dist/SHA256SUMS)

**Версия 0.3.0:** единый комплект нативной печати и сканирования для Mac с Apple Silicon, без Rosetta, Intel-драйверов HP, HPLIP и Python на компьютере пользователя. Независимый проект, не официальный драйвер HP.

## Что работает

- Быстрая печать изображений из **Cmd+P**: отдельная очередь **HP M1217 PCLm 600**, A4, 600 dpi, 8-битный серый, JPEG-сжатие внутри PCLm.
- Исправлено зависание наших PCLm-заданий: учтены особенности числового разборщика прошивки и порядок полей полос.
- Исправлена ошибка `expected URF raster` в реальной цепочке Cmd+P. Штатный растеризатор macOS вызывается с правильным внутренним форматом.
- Планшет и ADF, цветное/серое сканирование, сохранение PDF/JPEG/PNG.
- Несколько листов или проходов в один PDF; имя файла задаёт пользователь.
- **Исправлено искажение цвета при сканировании многостраничного PDF.** Этот результат включён по подтверждению владельца; отдельный новый тест цвета для выпуска не проводился.
- Нативный ICA для **«Захвата изображений»** и кнопка **«Открыть сканер…»** у новой очереди.
- Старые очереди и драйверы не удаляются; принтер по умолчанию автоматически не меняется. Прошивка не обновляется.

## Совместимость: модели и текущая прошивка

| Модель / среда | Статус |
|---|---|
| **HP LaserJet Professional M1217nfw MFP**, Ethernet, прошивка **20200618** | Подтверждены PCLm 600 dpi, правильный размер A4, печать Cmd+P; владелец сообщает о значительном ускорении |
| Семейства **HP M1130 / M1210**, ветка пакета прошивки `LJM1130_M1210_M1217_FW_Update_Security` | Кандидаты на совместимость, **не проверены на этих моделях**. Общее имя прошивки не гарантирует одинаковые протоколы |
| Модификации только с USB | Этот выпуск **не поддерживает USB-транспорт**; требуется доступный сетевой IPP/PCLm и Marvell2 для сканирования |
| Apple Silicon, macOS **27.2** | Реально проверенная среда разработки и аппаратных проб |
| macOS **11 и новее**, Apple Silicon | Минимальная цель сборки/установки 11.0; остальные версии требуют проверки, это **не обещание работы на любой macOS** |
| Intel Mac, macOS 28 | Не проверено; Intel не поддерживается этим arm64-пакетом |

Для проверенного МФУ версия основного образа — **20200618**, версия Print после обновления — **20201023**. Это не обозначение самой новой прошивки для всех моделей. Ранние тесты сканера проводились и с 20110826; быстрый PCLm-путь подтверждён на 20200618. Обновление прошивки не входит в установщик.

## Установка на другом Mac

1. Подключите совместимое МФУ по Ethernet и узнайте его IPv4. Желательно закрепить адрес в роутере.
2. Скачайте **HP-M1217-Native-Print-Scan-0.3.0-arm64.pkg**, сверьте SHA256 и установите пакет.
3. Откройте **Программы → HP M1217 Setup**, введите IPv4 и подтвердите административную настройку очереди. Жёстко заданного адреса автора нет. Тестовые страницы не отправляются.
4. Разрешите **локальную сеть** для Setup, Native ICA и Native Scan, если macOS запрашивает. Если сканер ещё не обнаружен, повторите Setup после выдачи разрешения.
5. В Cmd+P выберите **HP M1217 PCLm 600**. Для сканирования используйте **HP M1217 Native Scan** либо «Захват изображений» → **HP M1217 Native ICA**.
6. Для обнаружения ICA оставляйте **HP M1217 ICA Discovery** (меню **HP Scan**) запущенным. После входа в систему его можно открыть вручную или добавить в объекты входа macOS. Установщик не добавляет скрытую фоновую службу.

Если компоненты уже установлены, пакет **отказывается их перезаписывать**. Закройте приложения и сохраните прежние компоненты перед новой установкой; не устанавливайте поверх работающего экземпляра вслепую. Пользовательская копия в `~/Applications` не удаляется.

Пакет не подписан Developer ID и не нотариализован. Исполняемые файлы имеют ad-hoc подпись. При блокировке используйте штатное разрешение macOS в «Конфиденциальность и безопасность», только если доверяете выпуску. Отключать защиту системы не требуется.

## Печать и качество

Печать — A4, серый, 600 dpi, односторонняя. Размещение и масштаб выбираются в приложении. Изображение при необходимости растеризуется на сетку 600 dpi: это сохраняет физический размер, но не добавляет деталей исходнику. Нативный фильтр использует Apple ImageIO с качеством JPEG 0.90: сжатие с потерями, не побайтовое сохранение полутонов. Прямой растр PCLm 300 dpi на проверенном МФУ выводится в половинном линейном размере и не используется очередью.

Контрольный файл PCLm 600 dpi, 4,95 МБ: подготовка **0,21 с**, передача с ожиданием ответа **23,53 с**, завершение замечено через **33,60 с**. Это ручная проба Python-прототипа. После установки нативной очереди владелец подтвердил правильную печать Cmd+P и заметно более высокую скорость; отдельного замера этой печати и точного коэффициента ускорения нет.

## Сканирование

Планшет: цвет/серый, 75/150/300/600 dpi. ADF: цвет, 75/150/300 dpi. Для объединения проходов в отдельном приложении используйте «Сканировать / добавить листы…», затем «Сохранить PDF…»; до 100 страниц. В «Захвате изображений» выберите PDF и «Объединить в один документ». Не открывайте одновременно два сеанса одного МФУ.

Отдельное окно «Результаты сканирования» может оставаться пустым, даже когда файлы сохранены. Цветовая калибровка и точное покрытие краёв не сертифицированы. Нет OCR, двустороннего ADF и гарантии всех комбинаций настроек. Для сканирования нужен сетевой Marvell2 (TCP 8290).

Сканы, `capture.asp` и журналы остаются локально. Сырые файлы содержат изображение документа — не публикуйте их в issues. Не включайте паспорта и другие персональные документы в диагностические архивы.

## Сборка, проверки и откат

Исходники: [печать](printing/pclm), [сканер](scanner), [единый пакет](unified). Для сборки нужны Apple Silicon, Command Line Tools и Python 3; Pillow/pypdf нужны только тестам печати.

```sh
python3 unified/build.py
python3 printing/pclm/test_filter.py
python3 unified/test_package.py
```

Сборка не устанавливает драйверы и не обращается к принтеру. Подробные результаты и ограничения — [TESTING.md](TESTING.md).

Для отката закройте приложения сканирования и завершите задания. Запустите с правами администратора `/Library/Printers/HPNative1217PCLm/uninstall.sh`: он удалит только новую очередь и переместит компоненты в `/Users/Shared/HP-M1217-backup-<время>`. Сканы, старые драйверы, исходная AirPrint и пользовательские копии приложений сохраняются. Для возврата восстановите компоненты из резервной папки и снова запустите Setup.
