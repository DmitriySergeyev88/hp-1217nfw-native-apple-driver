# HP M1217nfw Native Apple Driver

[English](README.en.md)

Экспериментальное нативное приложение **HP M1217 Native Scan** для сетевого сканирования на HP LaserJet Professional M1217nfw MFP с Mac на Apple Silicon. Независимый backend Marvell2, без Rosetta, HPLIP и Intel-библиотек HP.

**Предварительный выпуск 0.2.1:** приложение сканирования 0.2.0 и отдельный экспериментальный ICA-пакет для «Захвата изображений». Печать и прошивка не меняются. ICA сохраняет файлы, но отдельный список «Результаты сканирования» пока остаётся пустым. Это ограничение не исправлено.

## Возможности

- Планшет и ADF через Ethernet (TCP 8290).
- Планшет: цвет / серый, 75, 150, 300, 600 dpi; ADF: цвет, 75–300 dpi.
- Имя документа; отдельные PNG, JPEG и PDF каждого прохода.
- Один PDF из нескольких проходов: листы планшета по одному или несколько пачек ADF, в порядке сканирования. До 100 страниц; ограничение памяти одного прохода также действует.
- Объединение готовых PDF-страниц без повторной растеризации и масштабирования.
- Отказ от перезаписи существующего PDF, предупреждение о несохранённом общем документе.
- Исходные данные и журнал каждого прохода остаются локально. После перезапуска приложения очередь объединения не восстанавливается; отдельные PDF сохраняются.

## Установка

Скачайте `HP-M1217-Native-Scan-0.2.0-arm64.pkg` из [Releases](../../releases) или папки [dist](dist). Сверьте SHA256 с [dist/SHA256SUMS](dist/SHA256SUMS).

Пакет устанавливает только `/Applications/HP M1217 Native Scan.app`. Если приложение с таким именем уже находится там, установка прекращается: закройте его и переместите в резервную папку перед обновлением. Прежнее приложение в `~/Applications` не меняется; запускайте новую версию именно из `/Applications`.

Сборка имеет локальную ad-hoc подпись; пакет **не подписан Developer ID и не нотариализован Apple**. macOS может блокировать запуск скачанного пакета. Используйте штатное подтверждение в «Конфиденциальность и безопасность», только если доверяете этому выпуску; отключать защиту системы не требуется. Альтернатива — собрать исходники локально.

При первом подключении разрешите приложению доступ к локальной сети в настройках macOS.

## Сканирование

1. Закройте «Захват изображений» и другие программы сканирования: устройство обслуживает один сеанс.
2. Укажите IPv4 сканера (адрес запоминается), источник, разрешение, режим и имя документа.
3. Нажмите **«Сканировать / добавить листы…»**. При первом проходе выберите папку; там создаётся отдельная папка документа.
4. Для планшета поменяйте лист и снова нажмите эту кнопку. ADF принимает все загруженные листы за проход.
5. Нажмите **«Сохранить PDF…»**, выберите имя и место общего файла. Если имя занято, выберите другое.
6. **«Новый документ»** начинает отдельную подборку. Исходные файлы предыдущей не удаляются.

В каждой папке `part-*` остаются PDF, PNG, JPEG, `capture.asp`, резервные настройки и `diagnostic.log`. Сырые файлы содержат изображение документа: не публикуйте их вместе с отчётом об ошибке. Приложение не отправляет сканы на внешние сервисы.

## Проверки и ограничения

Проверено на macOS 27.2 / arm64 и HP M1217nfw с прошивкой 20110826. Ранее выполнены реальные проверки планшета, одно- и двухлистового ADF, 300 dpi. Изменения 0.2.0 проверены автоматическими тестами имён, объединения нескольких PDF, порядка/размеров страниц и защиты файлов; **новый пользовательский сценарий ещё не проверен физическим сканированием**.

Поддержка macOS 28, Intel Mac и других моделей не заявляется. Точное покрытие краёв A4 и цветовая калибровка не завершены. ADF может возвращать немного меньший растр; недостающие пиксели не дорисовываются. Нет двустороннего ADF, OCR, удаления пустых страниц или автоматического поворота. При ошибке завершения сеанса приложение блокирует повторный скан: проверьте устройство и журнал, не повторяйте задание вслепую. Восстановление после сетевого разрыва ограничено.

## Сборка и тесты

Нужны Apple Silicon, macOS 27.2+, Command Line Tools (clang, codesign, pkgbuild) и Python 3. Сторонних библиотек нет. Значение «27.2+» — ограничение запуска, а не обещание проверки будущих macOS.

```sh
sh scanner/build.sh
python3 build_installer.py
```

Тесты не обращаются к сканеру. Все общедоступные тестовые изображения синтетические. Для локальной установки в пользовательскую папку (без замены существующего приложения):

```sh
python3 scanner/install_app.py install
```

## Откат

Закройте приложение и переместите установленное `.app` в Корзину. Верните сохранённую прежнюю версию, если она была. Сканы находятся в выбранных вами папках и не удаляются. Пакет не имеет фоновых служб и не меняет драйверы печати или старый сканер HP.

Для установки через пользовательский скрипт доступен `python3 scanner/install_app.py rollback`: он перемещает только проверенное приложение из `~/Applications` в Корзину.

## ICA — «Захват изображений»

Скачайте отдельный `HP-M1217-Native-ICA-0.2.1-arm64.pkg` из [Releases](../../releases). Он устанавливает только:

- `/Library/Image Capture/Devices/HP M1217 Native ICA.app`;
- `/Applications/HP M1217 ICA Discovery.app`.

Требуется администратор. При наличии любого из этих компонентов установщик откажется от замены. Для обновления закройте «Захват изображений», завершите прежний Discovery и переместите **только эти компоненты** в резервную папку. Если прежний Discovery находится в `~/Applications`, сохраните его, но не запускайте одновременно с новым. Старый драйвер HP и отдельное приложение сканирования сохраняются.

Откройте новый **HP M1217 ICA Discovery** из `/Applications`, введите IPv4 своего МФУ. Помощник остаётся в строке меню как **HP Scan**; там можно поменять адрес, предварительно закрыв сеанс сканирования. Запускайте его вручную после входа в систему: автозапуск не устанавливается. Разрешите локальную сеть для ICA и помощника, если macOS запросит доступ.

Откройте «Захват изображений» и выберите **HP M1217 Native ICA**. Для нескольких страниц ADF выберите PDF и «Объединить в один документ». Проверяйте файл в выбранной папке: отдельное окно результатов может быть пустым. Не открывайте одновременно старый сканер HP или standalone-приложение — МФУ обслуживает один сеанс.

В пакет включена версия доставки изображений после отката неудачного изменения уведомлений: регрессия с незавершающимся индикатором не включена. Базовая версия проверена на планшете и ADF, включая двухстраничный PDF; **новая настройка адреса и этот установочный пакет ещё не проверены физическим сканированием**. Пакет имеет те же ограничения подписи и нотариализации, что standalone.

Сборка после `sh scanner/build.sh`: `python3 scanner/ica/build_ica.py`. Проверка пакета без установки и сканирования: `python3 test_ica_installer.py`. Диагностический `ICAClient` не входит в установщик; запуск с путём папки инициирует физический скан, поэтому не используйте его как автоматический тест.

Откат: завершите «Захват изображений» и Discovery, переместите два указанных новых компонента в Корзину (для модуля потребуется администратор), верните резервные копии. Не удаляйте остальные компоненты Image Capture. Сканы и настройки сохраняются.
